# Avito Заметки

Расширение Chrome для личных заметок на любых страницах Avito.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное».
4. Выберите папку с этим расширением.
5. Откройте или обновите страницу Avito.

## Использование

- Кнопка «Заметка» находится в левом верхнем углу.
- Рядом с ней кнопка «Все заметки» открывает список сохранённых объявлений.
- В списке показываются ссылка, название, цена и сокращённый текст заметки; клик по карточке открывает объявление.
- Если для текущего адреса есть текст, кнопка становится зелёной.
- Пустая заметка удаляется после сохранения.
- Сочетание `Ctrl+Enter` или `Cmd+Enter` сохраняет заметку.
- При первом сохранении заметки сохраняются название объявления, цена, время сохранения и параметры из блока `#bx_item-params`.
- При последующем редактировании текста сохранённые цена и время не меняются.
- Ниже отображается история изменений заметки с датой, временем и сохранённым текстом.

Заметки хранятся в локальном хранилище Chrome и не отправляются на сервер Avito.
